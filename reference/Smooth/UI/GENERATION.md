# Smooth UI art provenance

The title painting, map panorama, Tala portraits, eight skill pictograms and interface marks were generated with OpenAI ImageGen. The AI-assisted source atlases are preserved here. The Unity-ready textures are cropped and fitted derivatives in `Assets/Art/Smooth/UI`.

The map uses the capiz parol, path diamond and Lola marker from the interface sheet. The finale bell derives from the smooth [interaction stage](../Interactions/GENERATION.md) with its red warning accent muted for the map. The rounded panel, map plate, and HUD gradient are generated geometry. Liberation Sans SDF and its outline material are the existing TextMesh Pro assets already bundled in the project. The smooth Lola, Anino and Bellkeeper portraits are reused from the [creature stage](../Creatures/GENERATION.md). The letter reuses its smooth pickup illustration.
