# Smooth creature and character art sources

The five source PNGs in this folder use the built-in ImageGen tool. They are AI-assisted illustrations. The approved smooth Tala sprite supplied the style reference, and each original creature supplied the design reference.

| Cast member | Source and use |
| --- | --- |
| Anino | `anino-portrait.png` is a new dialogue portrait. The patrol renders four approved smooth Tala run frames with the existing dark silhouette material and separate pale eyes. The Spirit chase still uses the selected Tala avatar's live silhouette. |
| Tikbalang | `tikbalang-poses.png` supplies a four-frame left-facing walk, with an umber coat, long mane, woven waist wrap and hoofed stance. |
| Manananggal | `manananggal-poses.png` supplies four left-facing wing phases. The final revision gives the adult creature a distinct face and long unbound hair while retaining the original wing and torso design. |
| Lola | `lola-poses.png` supplies the four original gestures. The dialogue portrait is a crop of the same illustration. |
| Bellkeeper | `bellkeeper-poses.png` supplies idle, stunned, tolling and defeated states. The dialogue portrait comes from the idle image. |

The body sprites are fitted to their original world rectangle and pivot. Each set uses a shared scale across poses. The normal campaign still references its original sprite catalog.
