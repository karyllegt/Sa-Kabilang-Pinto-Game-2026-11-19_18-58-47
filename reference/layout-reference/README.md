# Layout reference (Boomerang2D sandbox demo)

Viewing only. Do NOT copy these into the game or reuse the art, font, text or code. They show the layout ideas that inspired the menu box, dialog box with portrait, level map with nodes, heart HUD and popup box. The full demo (`boomerang-sandbox-windows-2.zip`, a Windows build) is on the developer's computer; if you want to read it, ask the developer for its path, extract it into a NEW empty folder outside the Unity project, and never run its .exe.
